## 🚀 Публикация на GitHub Pages

### Автоматический деплой (GitHub Actions)

Этот репозиторий настроен на автоматическую публикацию через GitHub Actions.

**Как это работает:**
1. При каждом push в ветку `main` запускается workflow
2. Собирается production-версия приложения (`npm run build`)
3. Артефакты загружаются на GitHub Pages
4. Сайт становится доступен по адресу: `https://<username>.github.io/<repo-name>/`

**Настройка:**
1. Перейдите в **Settings → Pages** вашего репозитория
2. В разделе **Build and deployment → Source** выберите **GitHub Actions**
3. Готово! Следующий push в `main` автоматически опубликует сайт

### Ручная публикация

Если нужно опубликовать вручную:

```bash
# 1. Установите зависимости
npm install

# 2. Соберите production-версию
npm run build

# 3. Содержимое папки dist/ загрузите на хостинг
# Для GitHub Pages можно использовать gh-pages:
npm install -g gh-pages
gh-pages -d dist
```

## 📝 Тема проекта

**Система управления заявками на ремонт оборудования**

- **Главная сущность:** Заявка на ремонт
- **Справочник:** Участок / агрегат (5 записей)
- **Роли:**
  - Диспетчер — создаёт заявки, назначает исполнителей
  - Инженер — принимает в работу, закрывает заявки
- **Статусы:** New → InProgress → Closed / Cancelled
